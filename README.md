# 项目目的

在保留 Mihomo 原有规则和兜底策略的前提下，根据实际连接证据判断直连或代理，为后续连接提供有时效的路由选择。

本文对应当前 PR 开发版本，尚未合并 main。

# 用途

用于需要保留已有规则、对未覆盖目标进行异步路由判断的环境。未知连接先走原有 fallback；后台判定和学习结果只影响后续连接，不阻塞首次连接。

# 目前实现功能

- 读取配置副本，检查支持范围并生成规则预览；已有具体规则保持优先。
- 采集 DNS、直连 TLS 和代理 TLS 证据，调用模型提出选择，再由本地证据与概率门槛决定是否接受；证据不足时保留 `UNCERTAIN`。
- 显式启用后，可发布受控学习规则，校验更新回读，按 TTL 清理；支持监督运行、停止清空和所属会话的恢复。
- 支持维护窗口暂停、清空和恢复。运行前必须设定开始时间、时区、持续时间及恢复方式。
- 提供 Windows 便携包、离线配置检查和状态查询；默认禁用，控制器与凭据不预填。

真实 DNS、直连 TLS、显式 VLESS TLS 和模型 API 连通已验证；最近两个目标因概率未达门槛保留 `UNCERTAIN`，真实学习发布尚未验收。

操作、停止与恢复见[使用说明](PORTABLE_QUICKSTART.md)；各版本验收范围见[交付状态](DELIVERY_STATUS.md)。

# 下一阶段目标

- 验证真实学习规则的发布、回读、原规则优先级、TTL、停止清理及故障恢复。
